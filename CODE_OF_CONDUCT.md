# Código de conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: trato respetuoso, críticas al código y no a las personas, y tolerancia cero con el
acoso. Si ves un comportamiento inaceptable, comunícalo a través del formulario de contacto de
[alexvendrell.com](https://alexvendrell.com/contactar/).
